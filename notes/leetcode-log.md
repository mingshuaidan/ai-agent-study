**Java 对照**：Java 用 `HashMap<Integer, Integer>`，Python 用 `{}` 字典，`map.get(k)` ↔ `d.get(k)`。

## Java 八股（每天 20 分钟）

**今日专题：HashMap 底层原理**

- 数组 + 链表 + 红黑树（JDK8 起）
- 默认容量 16、负载因子 0.75、扩容翻倍
- 链表长度 > 8 且数组长度 ≥ 64 时转红黑树
- `put` 流程：算 hash → 定位桶 → 比较 key → 插入/覆盖
- 线程不安全，并发场景用 `ConcurrentHashMap`（分段/CAS + synchronized）
